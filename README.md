A 4 KB Python chess engine (v6): plain alpha-beta search with a transposition table, a real PeSTO tapered evaluation, contempt for draws (+10), and 110k nodes per move. Practice Elo ~1581 on average (trials 1654 / 1545 / 1545, 18 games: 11 wins, 6 draws, 1 loss), above the 1154 final floor.

## Run it

```sh
python3 main.py
```
